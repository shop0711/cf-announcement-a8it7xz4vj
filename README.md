# 店内アナウンス音声作成 v0.6

GitHub Pages / HTTPS 公開用のテスト版です。

## 目的
- PC / スマートフォン / タブレットからURLを開くだけで利用
- WebGPU対応端末では音声生成を端末内で実行
- 初回のみIrodori-TTS用ONNXモデルを取得し、以降はブラウザキャッシュを利用
- 初回ダウンロードは約1.25GB。スマートフォンではWi-Fi推奨
- iPhone / iPadではメモリ使用量を抑える読み込み方式を使用

## テスト版の注意
- 標準ボイスは同梱していません。
- 「管理・テスト用」から、利用許可のある参照音声を端末ごとに選択してください。
- GitHub PagesをPublicで公開した場合、URLを知る人以外も技術的にはアクセス可能です。
- `noindex` と `robots.txt` は検索除外の意思表示であり、アクセス制御ではありません。
